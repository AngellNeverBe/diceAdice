# diceAdice

一个 3D 骰子模拟桌面应用，基于 Three.js 物理引擎实时渲染，Tauri v2 打包为原生 Windows 应用。

支持 7 种主题配色、D4/D6/D8/D10/D12/D20 共 6 类骰子，最多同时投掷 20 个。Cannon-es 驱动物理碰撞，悬停高亮、双击聚焦，专业跑团伴侣。

## 使用

从 [Releases](../../releases) 下载 `diceAdice_x64-setup.exe` 或 `.msi` 安装。运行即用，无需额外环境。

## 技术栈

Three.js 0.160 · Cannon-es · Tauri v2 · Rust · WebView2
